2. Text Style (Utility Class Teks)

.text-start → Rata kiri (text-align: left)

.text-center → Rata tengah (text-align: center)

.text-end → Rata kanan (text-align: right)

.text-lowercase → SEMUA JADI KECIL

.text-uppercase → semua jadi besar

.text-capitalize → huruf pertama tiap kata besar

.fw-bold → teks tebal (font-weight: 700)

.fw-light → teks tipis (font-weight: 300)

.fst-italic → teks miring (font-style: italic)

Tampak seperti H1 (class .h1)

Tampak seperti H4 (class .h4)

Tampak seperti H6 (class .h6)

.text-primary → Biru

.text-success → Hijau

.text-danger → Merah

.text-warning → Kuning
